## 리눅스 디렉터리 구조
- 리눅스는 트리구조
- 파일을 효율적으로 관리하기 위해 디렉터리를 계층적으로 구성
- 모든 디렉터리의 출발점은 루트(root)이며, /으로 표현


## 리눅스 디렉터리 종류와 특징
- /: 파일 시스템이 있는 최상위 디렉터리로 루트 디렉터리라고 한다.
- /boot: 부트 디렉터리로 부팅에 관련된 파일이 있는 곳
- /proc: 시스템 정보를 가진 디렉터리이며 커널 기능을 제어하는 역할(CPU,메모리 사용량, 파티션 정보를 가지고 있음)
- /lib: 라이브러리 디렉터리
- /bin: 기본적인 명령어 저장(관리자를 포함한 모든 일반 사용자가 쓸 수 있는 기본적인 명령어)
- /dev: 장치파일 모음(하드, CD-ROM, 마우스 등)
- /etc: 시스템 설정 파일
- /root: 관리자용 홈 디렉터리
- /sbin: 시스템 관리와 관련된 실행 명령어 저장(최고 관리자만 쓸 수 있는 시스템 관리용 명령어)
- /usr: 사용자 디렉터리로 사용자 데이터나 애플리케이션 저장
- /home: 사용자 계정 디렉터리로 계정들의 홈 디렉터리가 위치함.<br>일반 사용자들이 로그인 시 처음으로 위치하게 되는 디렉터리.
- /var: 가변 자료 저장 디렉터리로 로그 파일이나 메일 데이터 저장
- /tmp: 각종 프로그램이나 프로세스 작업을 할 때 임시 생성 파일 저장.<br>모든 사용자에 대해서 읽기와 쓰기가 허용.
- /mnt: 임시 마운트할 때 사용.[^mnt]
- /lost+found: 결함이 있는 파일에 대한 정보가 저장되는 디렉터리


## 파일의 종류
- 파일: 효과적 관리를 위한 연관성(관련) 있는 정보들의 집합
- 링크 파일 - L: 리눅스에서 원본파일을 대신하여 윈도우이 바로 가기 아이콘처럼 다른 이름으로 파일명을 지정하는 것.
  - 심볼릭 링크와 하드링크가 있음[^sym][^hard]
- 장치 파일 - C: 리눅스 시스템에 연결된 장치들을 관리하기 위한 특수 목적의 파일.<br> ex)HDD, USB, CD-Rom, 키보드 등 본체에 연결할 수 있는 모든 것


## 절대 경로와 상대 경로
- 절대 경로: 모든 시작이 /(root)부터 시작
- 상대 경로: 모든 시작이 현재 디렉터리부터 시작
